# Styling, layout, theming

The `Styled` trait gives every element a wide, utility-CSS-like fluent API
(methods are generated from `Styled`'s trait macros in `crates/gpui/src/styled.rs`
— confirmed in core `gpui`). This file covers the API, a theme system,
responsive layout, and reusable component recipes.

> **Not in core gpui** (dropped from earlier drafts): palette color helpers
> (`blue_500()`, `gray_200()`, …), `input()`/`textarea()` elements, and
> `transition_*`/`duration_*`/`ease_*`/`scale_105()`-style animation helpers.
> Use `rgb(0x…)`/`Hsla { .. }`, `div()`-based inputs (see
> [`fundamentals.md`](fundamentals.md)), and build motion with the `Animation`
> primitives in your pinned gpui version (verify names against that exact crate).

## The styling API

```rust
div()
    // Colors (no palette; use hex)
    .bg(rgb(0x2563eb))            // background
    .text_color(rgb(0xffffff))    // text color
    .border_color(rgb(0xe5e7eb))  // border color

    // Spacing
    .p_4()      // padding all-sides
    .px_6()     // padding horizontal
    .py_2()     // padding vertical
    .m_4()      // margin
    .gap_3()    // gap between children

    // Sizing
    .w_full()               // width 100%
    .h_full()               // height 100%
    .w_64()                 // width: 16rem
    .size(px(200.))         // fixed width/height

    // Borders
    .border_1()             // 1px border
    .border_t_1()           // top border only
    .rounded_lg()           // large radius

    // Layout
    .flex().flex_col()
    .grid().grid_cols_3()   // 3 equal columns
    .absolute().top_4().right_4()
    .overflow_hidden()

    .cursor_pointer()
    .opacity(0.5)
    .debug()                // visible outline while debugging layout
```

### Colors

```rust
use gpui::{rgb, rgba, Hsla};

let solid = rgb(0x2563eb);                 // opaque hex
let half  = rgba(0x000000, 0.5);           // hex + alpha
let custom = Hsla { h: 0.6, s: 0.8, l: 0.5, a: 1.0 }; // HSLA literal
```

### Spacing & typography scales

Spacing follows a Tailwind-like scale (`0`, `0.5`, `1`, `2`, `3`, `4`, `6`,
`8`, `16`, `24`, …) usable as `p_*`, `px_*`, `py_*`, `m_*`, `mt_*`, `mb_*`,
`gap_*`, `top_*`, `left_*`, `inset_*`.

Text helpers: `text_xs()`, `text_sm()`, `text_base()`, `text_lg()`,
`text_xl()`, `text_2xl()`; weights `font_normal()`, `font_medium()`,
`font_semibold()`, `font_bold()`; plus `line_height()`.

The full helper set is generated by `style_helpers!()` in `crates/gpui/src/styled.rs`.
The names above are the common core; for any other helper, `grep` it in your
pinned crate before using — don't guess method names that may have drifted.

Base the whole app on one spacing/timing scale so screens stay consistent (this
is enforced by your theme, below).

## Theme system

Define a theme struct, implement `Global` to make it readable anywhere, and set
it once at startup.

```rust
use gpui::{Global, Hsla, rgb};

#[derive(Clone)]
pub struct AppTheme {
    pub background: Hsla,
    pub foreground: Hsla,
    pub primary: Hsla,
    pub primary_hover: Hsla,
    pub secondary: Hsla,
    pub destructive: Hsla,
    pub border: Hsla,
    pub mode_is_dark: bool,
    pub text_sm_px: f32,
}
impl Global for AppTheme {}

impl AppTheme {
    pub fn dark() -> Self {
        Self {
            background: rgb(0x0a0a0a),
            foreground: rgb(0xfafafa),
            primary: rgb(0x3b82f6),
            primary_hover: rgb(0x2563eb),
            secondary: rgb(0x1e293b),
            destructive: rgb(0xef4444),
            border: rgb(0x334155),
            mode_is_dark: true,
            text_sm_px: 14.0,
        }
    }

    pub fn light() -> Self {
        Self {
            background: rgb(0xffffff),
            foreground: rgb(0x0a0a0a),
            primary: rgb(0x2563eb),
            primary_hover: rgb(0x1d4ed8),
            secondary: rgb(0xf1f5f9),
            destructive: rgb(0xef4444),
            border: rgb(0xe2e8f0),
            mode_is_dark: false,
            text_sm_px: 14.0,
        }
    }
}
```

Register at startup and consume in `render()`:

```rust
cx.set_global(AppTheme::dark());

// inside a Render impl:
let theme = cx.global::<AppTheme>();
div().bg(theme.background).text_color(theme.foreground).child("Themed")
```

### Theme switching

```rust
cx.update_global(|theme, cx| {
    *theme = if theme.mode_is_dark { AppTheme::light() } else { AppTheme::dark() };
    cx.notify();
});
```

Semantic naming (primary/secondary/destructive/…) is what keeps light/dark and
future versions manageable — never hardcode presentation colors in views.

## Responsive layout

React to window resizes by observing bounds in your view (never read layout
inside `render`; see [`performance.md`](performance.md) — layout thrashing):

```rust
struct ResponsiveView {
    width: Pixels,
    _on_resize: Subscription,
}

impl ResponsiveView {
    fn new(window: &mut Window, cx: &mut Context<Self>) -> Self {
        let width = window.bounds().size.width;
        let _on_resize = cx.observe_window_bounds(window, |this, window, cx| {
            let new_width = window.bounds().size.width;
            if this.width != new_width {
                this.width = new_width;
                cx.notify();
            }
        });
        Self { width, _on_resize }
    }
}

impl Render for ResponsiveView {
    fn render(&mut self, _window: &mut Window, _cx: &mut Context<Self>) -> impl IntoElement {
        let is_wide = self.width >= px(768.0);
        div()
            .flex()
            .when(is_wide, |el| el.flex_row().gap_6())
            .when(!is_wide, |el| el.flex_col().gap_2())
            .child(sidebar_content())
            .child(main_content())
    }
}
```

Breakpoints are just constants — define `SM/MD/LG/XL` and branch with `.when()`.

## Reusable component recipes

Presentational components are small functions that take the theme (or the data
they need) explicitly — factory functions have no `cx`, so pass values in
rather than reading globals.

### Button (with variants)

```rust
use gpui::{MouseButton, MouseUpEvent};

enum ButtonVariant { Primary, Secondary, Ghost, Destructive }

pub fn button(
    theme: &AppTheme,
    label: &str,
    variant: ButtonVariant,
    on_click: impl Fn(&MouseUpEvent, &mut Window, &mut App) + 'static,
) -> impl IntoElement {
    let (bg, fg, hover_bg) = match variant {
        ButtonVariant::Primary => (theme.primary, rgb(0xffffff), theme.primary_hover),
        ButtonVariant::Secondary => (theme.secondary, theme.foreground, theme.primary_hover),
        ButtonVariant::Ghost => (
            Hsla { h: 0.0, s: 0.0, l: 0.0, a: 0.0 }, // fully transparent
            theme.foreground,
            theme.secondary,
        ),
        ButtonVariant::Destructive => (theme.destructive, rgb(0xffffff), theme.primary_hover),
    };

    div()
        .px_4().py_2().rounded_md()
        .bg(bg).text_color(fg).font_medium()
        .hover(|style| style.bg(hover_bg))
        .cursor_pointer()
        .on_mouse_up(MouseButton::Left, on_click)
        .child(label)
}
```

Call sites pass a listener built in `render()`:

```rust
button(&theme, "Save", ButtonVariant::Primary, cx.listener(Self::save))
```

### Card

```rust
pub fn card(theme: &AppTheme, title: &str, body: impl IntoElement) -> impl IntoElement {
    div()
        .bg(theme.background)
        .border_1().border_color(theme.border)
        .rounded_lg()
        .shadow_sm()
        .p_6()
        .flex().flex_col().gap_4()
        .child(div().text_lg().font_semibold().child(title))
        .child(body)
}
```

### Text field (visual shell)

Core gpui has no `input()` element; style the container and drive typing with
`on_key_down` (see [`fundamentals.md`](fundamentals.md)):

```rust
div()
    .flex().items_center()
    .w_full().px_3().py_2()
    .bg(theme.background)
    .border_1().border_color(theme.border).rounded_md()
    .focus(|style| style.border_color(theme.primary).border_1()) // requires track_focus/focusable
    .on_key_down(cx.listener(|this, event, _window, cx| { /* text handling */ }))
    .child(div().text_color(theme.foreground).child(self.input_text.clone()))
```

### Modal

```rust
pub fn modal(theme: &AppTheme, title: &str, body: impl IntoElement) -> impl IntoElement {
    div()
        .absolute().inset_0()
        .flex().items_center().justify_center()
        .bg(rgba(0x000000, 0.5))          // backdrop
        .child(
            div()
                .bg(theme.background)
                .rounded_lg().w(px(500.))
                .flex().flex_col()
                .child(div().p_6().text_lg().font_semibold().child(title))
                .child(div().flex_1().overflow_y_auto().p_6().child(body)),
        )
}
```

### Split pane and tabs

```rust
pub fn split_pane(left: impl IntoElement, right: impl IntoElement) -> impl IntoElement {
    div().flex().flex_row().h_full()
        .child(div().flex_1().overflow_y_auto().child(left))
        .child(div().flex_1().overflow_y_auto().child(right))
}

fn tab_label(label: SharedString, active: bool, theme: &AppTheme) -> impl IntoElement {
    div()
        .px_4().py_2().cursor_pointer()
        .when(active, |el| el.text_color(theme.primary).border_b_1().border_color(theme.primary))
        .child(label)
}

pub fn tabs(
    theme: &AppTheme,
    items: Vec<(SharedString, impl IntoElement)>,
    active: usize,
) -> impl IntoElement {
    div().flex().flex_col()
        .child(
            div().flex().border_b_1().border_color(theme.border)
                .children(items.iter().enumerate().map(|(i, (label, _))| {
                    tab_label(label.clone(), i == active, theme)
                })),
        )
        .child(div().flex_1().p_4().child(items[active].1))
}
```

## Best practices

- **Theme-first**: read colors/spacing from `AppTheme`, never hardcode.
- **Gap over margin** for flex/grid children: `.gap_*()`.
- **Overflow**: pair scrollable regions with `overflow_y_auto()`/`overflow_x_auto()`.
- **Visual hierarchy** via size, weight, and spacing — not just color.
- **Focus visibility**: every interactive element needs `.track_focus()` plus a
  `.focus(...)`/`.focusable()` affordance; see [`fundamentals.md`](fundamentals.md).
- **Accessibility first pass**: keep contrast ≥ 4.5:1 for body text, and add
  semantic `.role()`/`.aria_label()` where relevant.
